# 프로젝트 제안서
# JavaFX 기반 무인 주차 관리 시스템

## 1. 프로젝트 개요

### 1.1 프로젝트 주제

**JavaFX 기반 무인 주차 관리 시스템 (Smart Parking Management System)**

본 프로젝트는 JavaFX를 활용하여 차량의 입차부터 출차까지의 주차 관리 과정을 자동화하는 데스크톱 애플리케이션을 개발하는 것을 목표로 한다.

사용자가 차량 번호를 입력하거나 카메라 인식 버튼을 통해 차량 정보를 등록하면, 시스템은 주차 가능 공간을 확인하고 주차 구역을 관리한다. 또한 차량별 입차 및 출차 시간을 기록하여 주차 요금을 자동으로 계산하고, 결제 및 차량 위치 안내 기능을 제공한다.

실제 주차장의 모든 하드웨어를 연결하는 대신, 번호판 인식 및 차단기 작동 과정을 UI와 데이터 처리 로직으로 시뮬레이션하여 무인 주차 시스템의 핵심 기능을 구현한다.

### 1.2 프로젝트 개발 목적

- 차량의 입출차 정보를 체계적으로 관리하여 주차장 운영의 효율성을 높인다.
- 주차 공간의 점유 상태를 실시간으로 확인하여 잔여 주차 공간을 안내한다.
- 입차 및 출차 시간을 기반으로 주차 요금을 자동 산정한다.
- 무인 결제 기능을 통해 별도의 관리 인력 없이 출차 정산이 가능하도록 한다.
- 차량 번호를 이용하여 주차 위치를 조회하고 사용자에게 출차 편의성을 제공한다.
- Java 객체 지향 프로그래밍(OOP)을 활용하여 기능별 클래스를 설계하고 유지보수하기 쉬운 구조를 구현한다.

## 3. 시스템 아키텍처 및 데이터 관리 개요

### 3.1 시스템 아키텍처

본 시스템은 JavaFX 기반의 사용자 인터페이스와 순수 Java 객체 지향 프로그래밍을 활용한 비즈니스 로직, 그리고 인메모리 데이터 저장소로 구성한다.

| 계층 | 사용 기술 | 주요 기능 |
|---|---|---|
| 프론트엔드(UI) | JavaFX + FXML | 주차 현황, 차량 입출차, 결제, 위치 조회 화면 |
| UI 설계 도구 | Scene Builder | FXML 기반 화면 구성 및 이벤트 연결 |
| 비즈니스 로직 | Java OOP | 입출차 처리, 요금 계산, 결제 및 주차 위치 관리 |
| 데이터 저장소 | ArrayList<T> | 차량 기록, 주차 공간, 결제 내역 관리 |

### 3.2 데이터 관리 방식

데이터 저장소는 별도의 데이터베이스 대신 Java의 `ArrayList<T>` 컬렉션을 활용한다.

차량 입출차 기록, 주차 공간 상태, 결제 내역을 각각 별도의 컬렉션으로 관리하며, 서비스 클래스에서 데이터를 추가하거나 검색하고 수정하도록 설계한다.

| 컬렉션 | 저장 데이터 | 주요 용도 |
|---|---|---|
| `slotList` | `ArrayList<ParkingSlot>` | 주차 구역 및 점유 상태 관리 |
| `recordList` | `ArrayList<ParkingRecord>` | 차량 입출차 기록 관리 |
| `paymentList` | `ArrayList<Payment>` | 결제 내역 및 정산 상태 관리 |

※ 인메모리 방식이므로 프로그램을 종료하면 데이터가 초기화된다. 본 프로젝트에서는 핵심 기능 구현과 객체 간 데이터 흐름 검증에 집중하며, 영구 저장은 구현 범위에서 제외한다.

## 4. 주요 구현 기능

### 4.1 개발자 A: 출입 통제 및 주차 안내 시스템

개발자 A는 차량이 주차장에 진입하는 순간부터 주차 공간에 배정되기까지의 과정을 담당한다.

#### 기능 1. 주차 구역별 상태 관리

- 전체 주차 공간을 일정한 번호와 구역으로 구분한다.
- 각 주차 공간은 차량의 점유 여부를 나타내는 `isOccupied` 변수를 가진다.
- 차량 입차 시 비어 있는 주차 공간을 검색하여 배정한다.
- 차량 출차 시 해당 주차 공간의 점유 상태를 해제한다.
- JavaFX 대시보드에서 주차 공간별 상태를 색상이나 아이콘으로 표시한다.

#### 기능 2. 차량 입출차 시간 기록

- 차량 번호를 입력받아 유효성을 검사한다.
- 입차가 승인되면 현재 시간을 입차 시각으로 기록한다.
- 출차가 처리되면 현재 시간을 출차 시각으로 기록한다.
- 차량별 입출차 기록을 `ParkingRecord` 객체로 관리한다.
- 동일 차량의 중복 입차 및 미등록 차량의 출차를 방지한다.

#### 기능 3. 번호판 인식 모듈 시뮬레이션

- 차량 번호 입력을 위한 텍스트 필드를 구현한다.
- 카메라 인식 버튼을 배치하여 번호판 인식 과정을 시뮬레이션한다.
- 버튼 클릭 시 입력된 차량 번호를 검증한다.
- 검증에 성공하면 `ParkingRecord` 객체를 생성한다.
- 생성된 객체를 `ArrayList<ParkingRecord>`에 추가한다.
- 실제 카메라 및 OCR 기술은 사용하지 않고 사용자 입력을 통한 인식 과정으로 대체한다.

#### 기능 4. 출입 통제 및 차단기 제어

- 차량 번호 검증 및 주차 공간 확인이 완료되면 입차를 승인한다.
- JavaFX 레이블과 이미지를 활용하여 차단기 상태를 표시한다.
- 입차 승인 시 `CLOSED`에서 `OPEN`으로 상태를 변경한다.
- 일정 시간이 지난 후 차단기가 다시 닫히는 과정을 시각적으로 표현한다.
- 주차 공간이 없거나 차량 정보가 유효하지 않으면 입차를 거부한다.

#### 기능 5. 잔여 주차 공간 실시간 안내

- `slotList`를 순회하여 비어 있는 주차 공간을 계산한다.
- `isOccupied == false`인 공간을 카운트한다.
- 전체 주차 면수와 잔여 주차 면수를 대시보드에 표시한다.
- 차량 입차 및 출차가 발생할 때마다 주차 현황을 갱신한다.

### 4.2 개발자 B: 요금 정산 및 차량 위치 안내 시스템

개발자 B는 차량 출차 과정에서 발생하는 요금 계산, 결제 처리 및 주차 위치 조회 기능을 담당한다.

#### 기능 1. 주차 요금 산정 알고리즘

- 차량 번호를 입력받아 해당 차량의 입차 기록을 검색한다.
- 입차 시각과 출차 시각의 차이를 분 단위로 계산한다.
- 기본 주차 시간과 기본 요금을 적용한다.
- 기본 시간을 초과한 경우 초과 시간에 따른 추가 요금을 계산한다.
- 최종 주차 요금을 사용자에게 표시한다.

#### 기능 2. 무인 정산 및 결제 프로세스

- 차량 번호를 입력하여 해당 차량의 주차 기록을 조회한다.
- 입차 및 출차 시각을 기반으로 주차 요금을 계산한다.
- 차량 번호, 주차 시간, 최종 요금을 포함한 청구서를 출력한다.
- 현금 및 카드 결제 버튼을 제공한다.
- 결제 버튼 클릭 시 결제 수단과 금액을 포함한 `Payment` 객체를 생성한다.
- 생성된 결제 객체를 `ArrayList<Payment>`에 추가한다.
- 결제가 완료되면 해당 `ParkingRecord`의 정산 상태를 변경한다.
- 정산이 완료된 차량만 출차할 수 있도록 처리한다.

※ 실제 금융 결제 시스템과 연결하지 않고 버튼 클릭을 통한 결제 완료 시뮬레이션으로 구현한다.

#### 기능 3. 주차 위치 확인 및 안내 서비스

- 차량 위치 조회 화면에서 차량 번호를 입력받는다.
- `recordList`에서 해당 차량의 주차 기록을 검색한다.
- `slotList`와 차량 기록을 대조하여 현재 점유 중인 주차 공간을 확인한다.
- 주차 구역과 주차 면 번호를 사용자에게 출력한다.
- 차량 번호가 존재하지 않거나 이미 출차한 차량이라면 안내 메시지를 표시한다.

예시 출력:

```text
[차량 위치 조회 결과]

차량 번호: 12가 3456
주차 구역: A구역
주차 면 번호: A-05
주차 상태: 주차 중
```

## 8. 결론

본 프로젝트는 JavaFX 기반의 무인 주차 관리 시스템을 개발하여 차량 입차, 주차 공간 관리, 요금 정산, 결제 및 차량 위치 안내까지의 전반적인 주차 프로세스를 하나의 애플리케이션으로 구현하고자 한다.

개발자 A는 차량 입차와 주차 공간 관리 및 출입 통제 기능을 담당하고, 개발자 B는 요금 계산과 결제 및 차량 위치 안내 기능을 담당한다. 각 기능은 공통 데이터 모델과 서비스 클래스를 통해 연동한다.

이를 통해 Java의 객체 지향 프로그래밍, 컬렉션을 활용한 데이터 관리, JavaFX 기반 GUI 구현 능력을 종합적으로 활용하고, 실제 생활에서 활용 가능한 무인 주차 관리 시스템의 기본 구조를 구현하는 것을 최종 목표로 한다.
